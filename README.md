# AI-Powered Multi-SIEM SOC Detection & Incident Response Lab

## Project Overview

This project is a simulated Security Operations Center (SOC) environment built using **Microsoft Sentinel and Splunk**.

The goal is to detect, investigate, hunt, and respond to realistic security incidents using security telemetry from Windows, Sysmon, and Microsoft Entra ID.

The project implements equivalent security detections in **KQL and SPL**, maps detected activity to **MITRE ATT&CK**, and uses **Python, APIs, and AI-assisted analysis** to automate parts of the alert investigation and incident-reporting process.

## Objectives

* Build a realistic SOC monitoring environment.
* Collect and analyze security logs.
* Develop detections using Microsoft Sentinel and Splunk.
* Write and compare KQL and SPL detection logic.
* Investigate security alerts and build incident timelines.
* Perform threat hunting using SIEM data.
* Map detections to MITRE ATT&CK techniques.
* Automate alert enrichment using Python and APIs.
* Use AI to assist with alert analysis and incident reporting.
* Implement controlled security-response workflows.
* Document the entire project as a professional cybersecurity portfolio.

## Planned Attack Scenarios

2. Suspicious PowerShell Activity
