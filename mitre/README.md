# MITRE ATT&CK

This directory contains the MITRE ATT&CK mapping for the security behaviors detected in our SOC lab.

Each detection will be mapped to the relevant ATT&CK technique to show how the observed activity relates to known adversary behaviors.

The mappings will cover our attack scenarios, including authentication attacks, PowerShell activity, privilege escalation, lateral movement, and account compromise.

**Detection → Investigation → ATT&CK Technique**
