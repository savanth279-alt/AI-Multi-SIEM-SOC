# Attack Scenarios

This directory contains controlled security attack simulations performed in the lab to validate our SIEM detections and SOC investigation workflows.

### Scenarios

- Password Spraying / Brute Force
- Suspicious PowerShell Activity
- Privilege Escalation
- Lateral Movement
- Account Compromise

Each scenario will document the simulated activity, generated telemetry, Sentinel and Splunk detections, investigation process, MITRE ATT&CK mapping, and response.

**Simulation → Telemetry → Detection → Investigation → Response**
