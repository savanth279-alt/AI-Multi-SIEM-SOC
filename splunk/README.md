# Splunk

Splunk is used as the second SIEM platform in this project to collect, search, detect, and investigate security events.

We will use Splunk Processing Language (SPL) to build detections and perform threat hunting, then compare the detection and investigation workflow with Microsoft Sentinel.

### Detection Scenarios

- Password Spraying / Brute Force
- Suspicious PowerShell Activity
- Privilege Escalation
- Lateral Movement
- Account Compromise

### Objective

Demonstrate practical SOC detection and investigation using Splunk alongside Microsoft Sentinel.

**Log Collection → Detection → Alert → Investigation → MITRE Mapping → Response**
