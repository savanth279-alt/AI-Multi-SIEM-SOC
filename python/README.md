# Python

Python will be used as the integration and automation layer of the SOC project.

It will interact with SIEM APIs to retrieve and process security alerts, normalize relevant data, perform enrichment and event correlation, and prepare investigation context for the AI-assisted analysis layer.

### Objective

Demonstrate how Python can connect SIEM platforms with automated security analysis and AI-assisted SOC investigation.

**SIEM Alerts → Python → Enrichment & Correlation → AI Analysis → Analyst**
