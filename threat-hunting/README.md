# Threat Hunting

This directory contains proactive threat-hunting activities performed across Microsoft Sentinel and Splunk.

We will use KQL and SPL to search security telemetry for suspicious patterns that may not have generated alerts.

### Hunting Focus

- Suspicious authentication activity
- Abnormal PowerShell execution
- Unusual account behavior
- Suspicious process activity
- Lateral movement indicators

Hunting results will be documented with the investigation findings and relevant MITRE ATT&CK techniques.

**Telemetry → Hunt → Investigation → Findings**
