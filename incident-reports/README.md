# Incident Reports

This directory contains documented SOC investigations based on alerts generated during the lab.

Each report will include:

- Alert summary
- Timeline of events
- Investigation findings
- Affected users and systems
- Evidence from Sentinel and Splunk
- MITRE ATT&CK mapping
- Response actions
- Lessons learned

The reports demonstrate the complete SOC investigation process from alert triage to resolution.

**Alert → Triage → Investigation → Evidence → Response → Report**
